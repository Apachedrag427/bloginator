# Configuration Options

## Universal (works for all subcommands)

### `config <file>`

Specifies the config file's location

- Command Line: `-c <file>` or `--config <file>`
- Config File: `N/A`

### `verbose`

Outputs additional debug and trace information

- Command Line: `-v` or `--verbose`
- Config File: `verbose = true`

## bloginator build

### `output_folder <directory>`

Determines the folder that the built website structure will be put into

- Command Line: `-o <directory>` or `--output-folder <directory>`
- Config File: `output_folder = "<directory>"`
